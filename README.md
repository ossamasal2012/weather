# الطقس — تطبيق الطقس الاحترافي

تطبيق طقس أصلي لأندرويد (Kotlin + Jetpack Compose)، خلفياته المتحركة تتغيّر حسب حالة الطقس ووقت اليوم، بحث ذكي عن أي مكان في العالم، جودة هواء منفصلة، ونظام تحديثات تلقائي كامل يُبنى ويتم نشره عبر GitHub Actions فقط — بدون أي خادم خاص.

جميع الحقوق محفوظة لتطبيق الطقس من المطوّر العراقي أسامة 🇮🇶

---

## 1. نظرة سريعة على ما بُني

- **الواجهة**: Jetpack Compose بالكامل، بدون XML للشاشات. نظام تصميم "زجاجي" (glass) موحّد فوق خلفيات متحركة.
- **الخلفيات**: 13 حالة طقس مختلفة × 4 أوقات لليوم (فجر/نهار/غروب/ليل) = **52 خلفية متحركة مصمَّمة يدوياً**، مبنية بالكامل بالكود (تدرّجات + جسيمات مطر/ثلج/سحب/شمس/نجوم/برق) — لا صور خارجية، فتغطّي كل رمز طقس (WMO) يمكن أن يرجعه Open-Meteo دون استثناء.
- **مصدر البيانات**: Open-Meteo (الطقس + جودة الهواء + البحث الجغرافي)، كلها مجانية وبدون مفتاح API.
- **الموقع**: تحديد تلقائي دقيق (GPS) + عكس جغرافي لاسم المكان (مدينة - محافظة - دولة).
- **التحديثات**: فحص تلقائي عند كل فتح، تنزيل بشريط تقدّم حقيقي عبر `DownloadManager` (يكمل حتى لو أغلقت التطبيق)، وتثبيت تلقائي فوري.
- **الأيقونة**: أيقونة متكيّفة (Adaptive Icon) تعمل بشكل صحيح مع كل أشكال أيقونات الأنظمة (دائرية، مربعة، مربعة بزوايا دائرية).
- **الخط**: Cairo (خط عربي/لاتيني احترافي متعدد الأوزان)، مضمّن محلياً.

## 2. الخطوات المطلوبة قبل أول نشر

### أ) أنشئ مستودع GitHub وارفع الملفات
أنشئ مستودعاً جديداً على GitHub، وضع كل الملفات المرسلة بنفس المسارات الظاهرة أمام كل ملف (نفس بنية المجلدات تماماً).

### ب) عدّل اسم المستودع داخل الكود (خطوة إلزامية مرة واحدة)
افتح الملف:
```
app/src/main/kotlin/com/osama/weather/util/Constants.kt
```
وغيّر هذين السطرين إلى اسم المستخدم/المستودع الحقيقي لديك:
```kotlin
const val REPO_OWNER = "YOUR_GITHUB_USERNAME"
const val REPO_NAME = "YOUR_REPO_NAME"
```
هذا هو الرابط الذي يتحقق منه التطبيق عند كل فتح، ولأن الـ workflow ينشر دائماً بوسم `latest`، هذا الرابط لا يتغيّر أبداً بعد هذه الخطوة.

> إن أردت تغيير اسم الحزمة (`applicationId`) من `com.osama.weather` إلى شيء آخر، عدّله في `app/build.gradle.kts` (`namespace` و`applicationId`) وفي `namespace` بنفس الملف — لكن هذا اختياري تماماً.

### ج) مفتاح التوقيع — جاهز مسبقاً، لا تحتاج تولّده بنفسك
تم توليد مفتاح توقيع حقيقي وصالح لك بالفعل (مجلد `signing/` المرفق):
- `signing/release.keystore` — ملف المفتاح نفسه (احتفظ بنسخة منه في مكان آمن خاص بك فقط).
- `signing/GITHUB_SECRETS.txt` — القيم الأربع جاهزة للنسخ مباشرة.
- `signing/KEYSTORE_BASE64_value.txt` — القيمة الطويلة الجاهزة لسر `KEYSTORE_BASE64`.

انتقل مباشرة للخطوة (د) بالأسفل وانسخ القيم.

> **ملاحظة:** مجلد `signing/` هذا للاطّلاع والنسخ فقط — **لا ترفعه إلى المستودع على GitHub إطلاقاً** (`.gitignore` المرفق يستثني ملفات `.keystore` تلقائياً، لكن تأكد يدوياً أيضاً من عدم رفع مجلد `signing/` كاملاً). الأسرار تُنسخ فقط داخل خانات Secrets في إعدادات GitHub، وهي مشفّرة هناك ولا يراها أحد.

### د) أضف أسرار GitHub الأربعة
من إعدادات المستودع: **Settings → Secrets and variables → Actions → New repository secret**، أضف بالضبط (القيم كلها جاهزة في `signing/GITHUB_SECRETS.txt`):

| اسم السر | القيمة |
|---|---|
| `KEYSTORE_BASE64` | محتوى ملف `signing/KEYSTORE_BASE64_value.txt` كاملاً (سطر واحد طويل) |
| `KEYSTORE_PASSWORD` | الموجودة في `signing/GITHUB_SECRETS.txt` |
| `KEY_ALIAS` | `alTaqsWeatherKey` |
| `KEY_PASSWORD` | نفس قيمة `KEYSTORE_PASSWORD` تماماً (طبيعة نوع PKCS12) |

### هـ) ادفع أول Commit
بمجرد الدفع (push) إلى فرع `main`، سيعمل الـ workflow تلقائياً (تبويب **Actions**)، ثم يظهر إصدار باسم **latest** في تبويب **Releases** يحوي `app-release.apk` و`version.json`. هذا هو ملف الـ APK الذي توزّعه على المستخدمين لأول مرة.

## 3. كيف تُصدر تحديثاً لاحقاً

هذا هو نفس النظام الموصوف في ملاحظاتك، منطبق حرفياً:

1. افتح `app/build.gradle.kts`.
2. ابحث عن:
   ```kotlin
   versionCode = 1
   versionName = "1.0.0"
   ```
3. زد `versionCode` بالضبط رقماً واحداً (1 → 2 → 3 ...، **لا يُعاد للخلف أبداً**)، وغيّر `versionName` لأي نص وصفي تريده (مثلاً `"1.1.0"`).
4. احفظ وادفع (Commit + Push).
5. انتظر العلامة الخضراء ✅ في تبويب Actions.
6. كل من يفتح التطبيق (نسخة قديمة) سيرى رسالة "يتوفر تحديث جديد" تلقائياً، بشريط تنزيل حقيقي، وتثبيت تلقائي فوري عند اكتمال التنزيل (داخل التطبيق أو عند فتحه من جديد).

> إن نسيت رفع `versionCode`، سيُبنى التطبيق وينشر بنجاح لكن **لن يظهر أي إشعار تحديث لأي مستخدم**، لأن المقارنة تعتمد فقط على هذا الرقم.

```
├── app/

│       ├── AndroidManifest.xml

│       │   ├── data/

│       │   │   ├── repository/                # تحويل DTO → نماذج نظيفة
│       │   │   └── local/                     # تفضيلات المستخدم (DataStore)
│       │   ├── domain/model/                  # نماذج الطقس/الموقع/جودة الهواء
│       │   ├── location/                      # GPS + العكس الجغرافي
│       │   ├── update/                        # فحص/تنزيل/تثبيت التحديثات
│       │   ├── ui/
│       │   │   ├── theme/                     # الألوان، الخطوط (Cairo)
│       │   │   ├── components/background/     # الخلفيات المتحركة (52 حالة)
│       │   │   ├── components/                # بطاقات، رسوم، مؤشرات
│       │   │   ├── screens/                    # الرئيسية، البحث، جودة الهواء، التفاصيل، الإعدادات
│       │   │   └── navigation/
│       │   └── util/                          # تنسيق، تحويل وحدات، الثوابت
│       └── res/                                 # الأيقونة المتكيّفة، الخط، النصوص العربية
├── .github/workflows/build-release.yml        # البناء + التوقيع + النشر التلقائي
├── gradle/wrapper/                              # Gradle 8.13 (مُضمّن كاملاً)
├── gradlew / gradlew.bat
├── settings.gradle.kts
└── build.gradle.kts
```

## 5. الأذونات التي يطلبها التطبيق ولماذا

| الإذن | السبب |
|---|---|
| الموقع (دقيق + تقريبي) | لعرض طقس منطقتك تلقائياً عند فتح التطبيق |
| الإشعارات (Android 13+) | لإظهار شريط تقدّم تنزيل التحديث في الإشعارات |
| تثبيت تطبيقات من مصادر غير معروفة | مطلوب من نظام أندرويد لتثبيت أي APK خارج المتجر، بما فيها التحديثات |
| الإنترنت | لجلب بيانات الطقس وتنزيل التحديثات |

لا يطلب التطبيق أي إذن غير ضروري (لا كاميرا، لا جهات اتصال، لا تخزين خارجي).

## 6. ملاحظات تقنية مهمة

- **الحد الأدنى لإصدار أندرويد**: 8.0 (API 26) — مطلوب لدعم الأيقونة المتكيّفة والمسار البرمجي لإذن التثبيت.
- **الشاشة الكاملة**: يُخفي التطبيق شريط الحالة وشريط التنقل بالكامل (وضع Immersive)؛ يمكن للمستخدم سحب الحافة لإظهارها مؤقتاً عند الحاجة (سلوك أندرويد القياسي).
- **مصادر البيانات**: طقس وجودة الهواء والبحث الجغرافي، الثلاثة من Open-Meteo مباشرة، بلا أي بيانات وهمية.
- **الوحدات**: يمكن تغيير وحدة الحرارة (°C/°F) والرياح (كم/س، م/ث، ميل/س، عقدة) والهطول (ملم/إنش) من شاشة الإعدادات.
- **الاتجاه**: الواجهة بأكملها من اليمين لليسار (RTL) بشكل ثابت، بصرف النظر عن لغة نظام الجهاز.

## 7. اختبار محلي (اختياري)

يمكنك فتح المشروع مباشرة في Android Studio (Giraffe أو أحدث) وتشغيله على جهاز/محاكي دون الحاجة لأي إعداد إضافي؛ بدون أسرار GitHub، سيُستخدم توقيع Debug تلقائياً في وضع `assembleRelease` المحلي، وهذا كافٍ للتجربة فقط (ليس للتوزيع العام).
